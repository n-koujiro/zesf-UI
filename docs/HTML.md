# HTMLで学んだこと
# リンクのソースコード
```
<a href="リンク先のURL">リンクテキスト</a>
```
- **href属性**：リンク先のURL（絶対URLや相対URL）を指定
- **リンクテキスト**：クリックすると表示される文字（リンク先の内容を明示するのが推奨）
- `<a>`タグの開始と終了でリンク領域を囲みます

# ulとliの箇条書き
```
<ul>
  <li>1つめの項目</li>
  <li>2つめの項目</li>
  <li>3つめの項目</li>
</ul>
```
`ul`と`li`を使うと、各項目の先頭が黒ポチの箇条書きとなります（この黒ポチのデザインは変えることができる
# ulとolの違い
- ul：順序を問わない箇条書き。通常は黒ポチで表示
- ol：順序が意味を持つ箇条書き。通常は番号付きで表示
